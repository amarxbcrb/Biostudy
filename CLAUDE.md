# BioStudy (biostudy.xyz) : récapitulatif pour les prochaines tâches

Site statique d'outils de biologie et de chimie pour étudiants, par Amar Bouchareb.
Chaque outil est un seul fichier `<Outil>/index.html` (HTML, CSS et JS dans le même fichier, sans framework ni build).

## Déploiement et git
- Outils gardés (demande de l'utilisateur) : BioCampus, BioPCR, BioChem, BioPrep, BioDilu, BioMicro, BioBand, BioConvert, **BioStat** (ajouté en octobre 2026 ; seul outil en plusieurs fichiers, un dossier par onglet), **BioGene** (ajouté en novembre 2026 : séquences, code génétique, CRISPR, plasmides, clonage). **edt, Lyon 1 Portail et BioFlow ont été supprimés** (récupérables dans git).
- **Cloudflare Pages** sert la racine du dépôt telle quelle : chaque fichier du dépôt est public (y compris ce fichier, donc aucun secret ici).
- Chaque push sur `main` est mis en ligne automatiquement.
- L'utilisateur autorise à **appliquer directement** : commit sur la branche de travail, puis push sur la branche et sur `main` (`git push origin HEAD:main`).
- L'utilisateur modifie parfois `main` lui-même (« Update index.html ») : faire `git fetch origin main` et un fast-forward avant de travailler.
- Les fonctions serveur sont dans `functions/api/*` (Pages Functions) :
  - `campus.js` (relais BioCampus avec cache Cloudflare, voir BioCampus) ;
  - `vitrine/[[route]].js` (+ `GET/POST site` : réglages du site).
- `functions/_middleware.js` : logo/favicon remplacés depuis le studio (fichiers KV `m:<id>`) et page 503 pour un outil en maintenance (bloque **tout le monde** ; l'admin, cookie `bs_adm` = sha256 de `VITRINE_CLE` posé à la connexion au studio, voit un bouton « Ouvrir l'outil (admin) » vers `?apercu=1` qui seul le laisse passer ; `mf_guard` dans `menu-flottant.js` recouvre aussi la page côté navigateur si une copie en cache a échappé au serveur). `_routes.json` limite les chemins qui invoquent les fonctions (quota gratuit) : **ajouter chaque nouvel outil** dans `_routes.json`, dans `OUTILS` du middleware et dans la liste `OUTILS` du studio.
- Un `LISEZMOI.txt` dans chaque dossier décrit son contenu (à tenir à jour).
- Liaisons Cloudflare :
  - stockage KV `VITRINE` ;
  - secret `VITRINE_CLE` (mot de passe du studio, **jamais dans le code**, et l'utilisateur le connaît déjà).

## Préférences de l'utilisateur
- Il écrit en français, de façon informelle et souvent en abrégé. Répondre en français.
- Il veut aller droit au but et économiser les tokens. Quand il le demande : pas de captures d'écran ni de tests longs.
- Les calculs doivent être **100 % fiables scientifiquement** : toujours vérifier les cas de référence (voir plus bas).
- Pour une refonte de design, il aime d'abord voir un aperçu. Pour les corrections, il veut qu'on les applique directement.
- Style visuel voulu : **Apple iOS 26 / Liquid Glass** :
  - tout est arrondi (capsules, rayon 999px), il n'aime pas les coins carrés ;
  - peu de conteneurs, avec des groupes façon **Réglages d'Apple** (lignes séparées par des filets fins, en-têtes de groupe en petites majuscules) ;
  - mode sombre aux couleurs Apple : fond `#000`, groupes `#1c1c1e`, accent `#0a84ff` / texte `#4da3ff`. Mode clair : fond `#f2f2f7`, groupes `#fff`, accent `#007aff`.
- **Couleurs système Apple selon l'endroit** (variables `--c-blue`, `--c-orange`… avec variantes clair/sombre) :
  - un accent par onglet (`#bc[data-tab]` → `--acc`, `--acc-tx` calculé par `color-mix`), icône de chaque onglet dans sa couleur ;
  - BioChem : pastille ronde colorée par type de grandeur (`DC` : masse orange, volume cyan, C bleu, γ sarcelle, M indigo, b violet, ρ brun, w rose) ;
  - BioPCR : numéros de réactifs colorés ; onglets bleu / violet / vert ;
  - BioCampus : chips par type de document (cours bleu, TD orange, TP sarcelle, examens rouge, résumés violet), pastilles des fonctions, onglets colorés. **Pas de vert sur BioCampus** (il n'aime pas) : marque, interrupteurs, « Actuelle » = accent bleu.
- **Glossaire harmonisé (révision scientifique d'octobre 2026, à respecter dans tout nouveau texte)** : solution mère (Cᵢ) / concentration finale (C_f) / volume final (V_f) ; facteur de dilution n (ex. 10) ≠ dilution 1/n (ex. 10⁻¹) ; « cône » (jamais « embout ») ; homogénéiser (vortex, pipetage ou retournement selon l'échantillon) ; centrifuger brièvement ; témoin négatif ; **PCR** : réaction (≠ tube ≠ échantillon), « Échantillons et témoins » + « Surplus » (réactions supplémentaires, en nombre ou %), « Réactions comptées dans le master mix », « Master mix à distribuer par tube », « ADN matrice à ajouter par tube », **eau exempte de nucléases** ; ADN polymérase ajoutée en dernier ; tailles d'ADN en **pb** / kb (pas « bp ») ; DO₆₀₀ ; UFC/mL ; temps de génération g, taux de croissance spécifique μ ; seuils (30–300 colonies, zone de linéarité de la DO, facteur DO → cellules) présentés comme **repères usuels**, jamais comme règles ; messages d'erreur = problème + comment corriger. Les relations restent écrites avec le point médian.
- **Vocabulaire scientifique** : « Grandeur recherchée », « Données », « Relation », point médian `·` dans les relations, unités g·L⁻¹, titre massique w, solution mère Cᵢ / concentration finale C_f, ADN matrice, amorces (F)/(R), Taq ADN polymérase.
- Barres (haut et bas) : **exactement le même verre** sur les deux :
  - `rgba(lg-rgb, .68)` avec `backdrop-filter: blur(22px) saturate(190%)` ;
  - reflet lumineux qui suit la souris (`::after` + `--mx/--my` + classe `lit`).
- Icônes : **Lucide** (trait fin, comme sur BioCampus), insérées en SVG dans le fichier. Il a rejeté Phosphor et le style Material sur BioChem. BioConvert utilise Material Symbols Rounded.
- Champs modifiables = capsule **bordée, fond transparent, bordure neutre `--fb`** (accent seulement au focus) ; unités = capsule grise pleine avec chevron. Pas de fond teinté (il n'aime pas). Ne jamais remettre des champs sans bordure.
- Lignes de saisie : **libellé à gauche, valeur + unité à droite sur la même ligne** (BioChem et BioPCR identiques). Sur mobile BioChem affiche le nom court (`s_*`), sur PC le nom complet (`v_*`).
- Retour haptique sur chaque bascule ou changement d'onglet (voir `buzz()` dans BioChem). Partout ailleurs : **`/haptique.js`** (chargé par `menu-flottant.js`) vibre à chaque clic sur un élément interactif. Les pages avec leur propre haptique portent `data-haptic="own"` sur `<html>` (accueil, BioChem, BioPCR, BioMicro, BioDilu, BioPrep, BioCampus). `window.bsBuzz(motif)` disponible.
- Saisie des nombres : décimale **et** scientifique (mantisse × 10^exposant), affichage des résultats à 4 chiffres significatifs.
- **Écriture des nombres choisie champ par champ, jamais de bascule globale** (l'utilisateur a demandé de supprimer le curseur « Décimale / Scientifique » partout) : chaque unité est une capsule qui ouvre une fenêtre façon BioChem, avec en haut « Écriture 1,5 | 1,5 × 10ⁿ » pour **ce champ seulement** (valeur convertie : 0,005 ↔ 5 × 10⁻³), puis les unités nommées, puis les molettes Masse | Volume pour les unités composées. Plus aucune liste `<select>` système pour les unités.
  - BioChem, BioDilu : `FX` (clés `bch_fx`, `bdl3_fx`), `isSci(id,k)`, `applyFx()`, `setFx()` ; classe `sci` sur `.ctl` ; capsules `.ucap` pour toutes les unités (`u1` unité unique, `u0` sans unité : affiche « 1,5 » ou « ×10ⁿ ») ; le résultat suit l'écriture du champ de la grandeur recherchée (`S.rsci`).
  - BioMicro : choix d'écriture seulement pour UFC/mL, k et cellules/mL (`tb.sci`) ; dilution toujours en 10ⁿ (`tb.fix`) ; le reste en décimale sans bouton.
  - BioConvert : même moteur que BioDilu (clé `bcv_fx`).
  - BioPrep : drapeau `<champ>S` (ex. `it.cS`, `P.VS`), classe `sci` sur `.nf`, `setFx()`.
  - BioDilu et BioPrep ont été modifiés directement dans le dépôt : les scripts de génération hors dépôt (`gen_dilu.py`, `gen_prep3.py`) ne sont plus à jour pour BioDilu.

## Application web (PWA) : UNE seule pour tout le site
- `/manifest.webmanifest` (nom BioStudy, `start_url` et `scope` = `/`, `orientation: portrait` ; iOS ignore ce réglage ; raccourci `shortcuts` vers `/BioCampus/`) lié depuis l'accueil (`index.html`) **et depuis BioCampus** (sans lien, Chrome / Edge Android répondaient « This app cannot be installed » sur la page BioCampus) : c'est la même et unique application. `/sw.js` (réseau d'abord, cache `bs-v1`, ignore `/api/` et `/studio/`).
- Logo de l'utilisateur (original `Pictures/Logo.png` supprimé, récupérable dans git) → icônes dans `Pictures/` (`icon-192`, `icon-512`, `maskable-512`, `apple-touch-icon`, `favicon`) ; `/favicon.png` = même logo.
- Les outils ont seulement favicon + apple-touch-icon + enregistrement de `/sw.js` (pas de lien manifest, pas de bouton « Installer »). **Ne jamais créer de manifest, d'icônes ou de service worker par outil.**
- `BioChem/sw.js` et `BioPCR/sw.js` ne sont plus que des « kill-switch » qui désinstallent les anciens SW par outil (on peut les supprimer dans quelques semaines).

## BioChem (`/BioChem/`) : implémentation de référence, propre et autonome
Cinq onglets :

| Onglet | Grandeurs | Loi |
|---|---|---|
| Molarité `mol` | m, M, V, C | C = m/(M·V) |
| Conc. massique `mas` | m, V, γ | γ = m/V |
| Molalité `mlal` | m, M, m_solv, b | b = m/(M·m_solv) |
| Masse volumique `rho` | m, V, ρ | ρ = m/V |
| Solution commerciale `pct` | w, ρ, M, C | C = 10·w·ρ/M |

- Unités de base : g, L, mol/L, g/L, g/mol, mol/kg, g/mL, %.
- Le JS est organisé en sections numérotées de 1 à 15 :
  - outils ;
  - icônes ;
  - textes FR/EN `T` ;
  - unités `D` et `fu(dim, u)` (unités nommées `u` et composées `r = [num, dén, facteur]`) ;
  - `TABS` (vars, `f` lois, `solve` par inconnue, `note`) ;
  - nombres ;
  - construction ;
  - grandeur à calculer ;
  - calcul ;
  - onglets ;
  - saisie ;
  - molettes d'unités ;
  - thème, langue, installation ;
  - historique ;
  - démarrage.
- **« Calculer »** : segment `.cal` (symbole + nom court) qui choisit l'inconnue (`S.tgt[tab]`).
  - Sa ligne est masquée.
  - Son contrôle d'unité est déplacé dans le résultat (`#ru`, fonction `dockUnit()`).
  - L'ancienne inconnue redevient saisissable avec sa valeur calculée.
- Identifiants :
  - valeur `${tab}-${k}` ;
  - exposant `${tab}-${k}-e` ;
  - unité `${tab}-${k}-u` (`<select>` pour une unité simple, `<button class="sel ucap" data-dim>` pour une unité composée, qui ouvre des molettes façon horloge `#upop`) ;
  - ligne `${tab}-r-${k}`.
- Résultat flottant `#mini` : quand le clavier est ouvert (mobile), il se place juste au-dessus via `visualViewport` (classe `kb` sur `#bc`, la barre d'onglets se masque). Même chose dans BioPCR.

- Erreurs gérées : `bad`, `neg`, `zero`, `ovf`, `pct` (w > 100 %).
- localStorage :
  - `bch_state` (valeurs + `_t` inconnues) ;
  - `bch_fmt` ;
  - `bch_tab` ;
  - `bioChemHistory` ;
  - `bioChemTheme` + `bioChemThemePeriod` ;
  - `bc_lang` (partagé avec BioConvert).
- Mise en page PC (≥ 1024×600) : barre d'onglets en haut au centre, saisie à gauche, résultat à droite.

### Cas de référence (à revérifier après toute modification des calculs)
- NaCl 0,5 M, 100 mL, M 58,44 → m = **2,922 g**
- 1 g de glucose (180,16) dans 50 mL → **111 mM**
- 1 µg, M 100, 1 mL → **10 pmol/µL**
- 10 mg / 5 mL → **2 µg/µL** ; 2 g / 100 mL → **2 % (m/V)**
- 5,844 g de NaCl dans 100 g d'eau → **1 mol/kg**
- 12,6 g / 10 mL → **1 260 kg/m³**
- HCl 37 %, d 1,19 → **12,08 M** ; H₂SO₄ 96 %, d 1,84, M 98,08 → **18,01 M**

## Pièges déjà rencontrés
- **Le flou disparaît** (`backdrop-filter`) quand un ancêtre :
  - a lui-même un `backdrop-filter`, un `filter` ou un `mask` ;
  - a une `opacity` < 1 (y compris pendant une transition) ;
  - a un `will-change: opacity` ;
  - a une animation avec `fill-mode: both`.

  Utiliser `animation-fill-mode: backwards`. Pour un voile de fond, animer `background` et `visibility`, pas `opacity` (voir `.ov` dans BioChem).
- Un sélecteur `#bc *` écrase les classes à cause de sa spécificité : utiliser `:where(#bc) *`.
- `[hidden]` est écrasé par `display:flex` : ajouter `[hidden]{display:none!important}`.
- Ouvrir les molettes d'unités ne doit pas changer l'unité (comparer avec `upPair()` avant d'appliquer).
- **Fenêtre d'unité `#upop` (BioChem/BioDilu/BioConvert/BioMicro/BioPrep)** : `upPlace()` bornait mal le haut → une fenêtre composée (molettes Masse|Volume) trop haute pour tenir au-dessus **et** en dessous de l'ancre basculait quand même en dessous et sortait du bas de l'écran sur PC (corrigé nov. 2026). Le haut est désormais clampé dans l'écran, et `.upop` a `max-height:calc(100dvh - 16px);overflow-y:auto`. **Garder ce clamp pour tout nouveau sélecteur en popup** (voir aussi `openPop` de BioGene).
- Haptique iOS : ignorer les clics venant de `[data-hap]` dans les écouteurs globaux.

- **Clavier Android** : quand il s'ouvre, la page devient plus large que haute et déclenchait la mise en page « paysage » (2 colonnes, outil illisible). Toutes les requêtes `(orientation:landscape)` ont `and (min-aspect-ratio:3/2)`, et le viewport a `interactive-widget=resizes-visual`. À garder pour tout nouvel outil.
