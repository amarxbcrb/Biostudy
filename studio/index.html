Connexion

Encore une étape dans Cloudflare

Le studio a besoin d'un espace de stockage pour enregistrer vos contenus. À faire une seule fois :

  1. Cloudflare → Storage & Databases → KV → Create a namespace, nom : biostudy-vitrine.
  2. Workers & Pages → votre projet → Settings → Bindings → Add → KV namespace : nom de variable VITRINE, espace biostudy-vitrine.
  3. Même page → Variables and Secrets → Add → type Secret, nom VITRINE_CLE, valeur : le mot de passe de votre choix.
  4. Deployments → relancez le dernier déploiement (Retry deployment).

Réglages du site

Tout le site

Site entier en maintenance

Accueil et tous les outils affichent la page d'attente. Vous gardez l'accès avec « Ouvrir le site (admin) ».

Messages des visiteurs

Bouton « Une idée, un problème ? » en bas du menu des outils. Les messages arrivent dans l'onglet Messages.

Mesurer l'audience

Affiche la demande d'accord (« Accepter » / « Continuer sans accepter ») et mesure les visiteurs qui acceptent. Désactivé : ni demande ni Google Analytics.

Sauvegarde

Télécharge un fichier avec les réglages, les contenus et les messages (les images restent sur Cloudflare).

Logo et icônes

Le logo sert aussi d'icône de l'application installée. Le favicon est la petite icône de l'onglet du navigateur (s'il est vide, le logo est utilisé). Image carrée conseillée, PNG, au moins 512 × 512 px.

Outils

Masqué : retiré du menu et de l'accueil (le lien direct marche encore). Nouveau : pastille orange dans le menu et sur l'accueil. Description : remplace le petit texte sous le nom. Maintenance : la page de l'outil affiche un message d'attente ; personne ne peut utiliser l'outil ; vous, connecté au studio sur ce navigateur, avez un bouton « Ouvrir l'outil » sur cette page pour le tester.

Notifications

Activer les notifications

Les visiteurs pourront s'abonner depuis le menu des outils (« Recevoir les notifications »). Android et ordinateur : dans le navigateur ou l'application installée. iPhone et iPad (iOS 16.4 ou plus) : seulement quand BioStudy est ajouté à l'écran d'accueil.

Les clés de sécurité sont créées une seule fois dans votre navigateur et gardées dans le stockage Cloudflare du studio : aucun réglage à faire dans Cloudflare.
